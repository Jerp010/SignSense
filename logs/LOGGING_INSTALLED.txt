HOW TO USE THE LOGGING SYSTEM
═════════════════════════════════════════════════════════════════════════════

STEP 1: RUN YOUR APPLICATION
────────────────────────────
  cd d:\CODE FOLDER JEFF\SignSense\signsense
  python main.py

STEP 2: USE THE APP NORMALLY
──────────────────────────
  - Go through menus
  - Play a level or use debug mode
  - Press ESC to exit

STEP 3: CHECK THE LOG FILE
──────────────────────────
  Windows PowerShell:
  
  # View last 100 lines
  Get-Content ../logs/signsense_*.log | Select-Object -Last 100
  
  # See all errors
  Get-Content ../logs/signsense_*.log | Select-String "ERROR|FAILED"
  
  # See all warnings (slow operations)
  Get-Content ../logs/signsense_*.log | Select-String "[WARN]|WARNING"
  
  # See final performance report
  Get-Content ../logs/signsense_*.log | Select-String "PERFORMANCE"

STEP 4: LOOK FOR ISSUES
──────────────────────
  1. Search for first "ERROR" or "[FAIL]" - usually the root cause
  2. Look for "[WARN]" entries - indicates slow loading (>1s, >5s)
  3. Check "Frame X | FPS: X" entries - should be ~30 FPS
  4. See PERFORMANCE REPORT at end for statistics


QUICK DEBUGGING EXAMPLES
═════════════════════════════════════════════════════════════════════════════

Issue: "App won't start"
Find in log: 
  [FAIL] FAILED: Open camera 640x480 | FileNotFoundError
  Solution: Camera is in use by another app or not connected

Issue: "Load takes 10 seconds"
Find in log:
  [WARN] DONE: Initialize play mode detectors | Time: 10.23s
  Solution: Models taking long to load - check file sizes, maybe download issue

Issue: "FPS keeps dropping from 30 to 10"
Find in log:
  DEBUG: Frame 100 | FPS: 30.0
  DEBUG: Frame 200 | FPS: 28.0
  DEBUG: Frame 300 | FPS: 10.2
  Solution: Check if background apps are running, or hands causing heavy processing

Issue: "Signs aren't being recognized"
Find in log:
  Error in Classifier: RuntimeError: [frame 42]
  Solution: Model failed on certain hand poses - may be temporary

TYPICAL LOG SESSION FLOW
═══════════════════════════════════════════════════════════════════════════

App starts
  -> Log: SESSION STARTED + Python version
  -> Log: Window created
  
User clicks menu
  -> Log: STATE: MAIN_MENU
  -> Log: -> Rendering MAIN MENU
  
User clicks Play
  -> Log: <- Main menu action: play
  -> Log: STATE: LEVEL_SELECT
  
User selects level
  -> Log: <- Level select result: letters
  -> Log: STATE: PLAY
  -> Log: -> Entering PLAY MODE | level=letters
  -> Log: [INIT] Initializing Camera
  -> Log: [OK] Camera opened (timing: 0.002s)
  -> Log: [OK] Initialize detectors (timing: 5.2s) <- Slow if >1s
  -> Log: DEBUG: Frame 1 | FPS: 30.0
  -> Log: DEBUG: Frame 30 | FPS: 30.1
  -> Log: (repeats every 30 frames)
  
If error occurs:
  -> Log: Error in Classifier: RuntimeError [frame 42]
  
User presses ESC
  -> Log: <- Exiting PLAY MODE | processed 450 frames
  
App closes
  -> Log: SESSION ENDED
  -> Log: PERFORMANCE REPORT with statistics

TROUBLESHOOTING THE LOGGING SYSTEM
═══════════════════════════════════════════════════════════════════════════

Q: "I don't see logs/ directory"
A: It's created automatically when you first run python main.py
   Check: d:\CODE FOLDER JEFF\SignSense\logs\

Q: "Log file is empty or missing"
A: Check that main.py imported logger successfully:
   from utils.logger import logger
   Should not have errors when importing

Q: "Logs have weird characters (unicode)"
A: Normal - the logs contain emoji indicators ([OK], [FAIL], [WARN])
   Just note what the symbols mean (see LOG_REFERENCE.txt)

Q: "How do I disable logging?"
A: Don't - it has negligible performance impact. But if you must:
   Edit signsense/utils/logger.py and remove the handlers

Q: "Where do I add logging to my own code?"
A: See LOGGING.md section "Integration with Your Workflow"
   Or IMPLEMENTATION_SUMMARY.md section "To add custom logging"
