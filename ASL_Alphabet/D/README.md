# ASL Sign for Letter D

## Instructions for Adding Media Files

This folder is designated for storing American Sign Language (ASL) handshape images and videos for the letter **D**.

### Supported File Formats

- **Images:** `.png`, `.jpg`, `.jpeg`
- **Videos:** `.mp4`

### File Naming Convention

Please use the following naming pattern for consistency:

- **Images:** `D_view_1.png`, `D_view_2.jpg`, `D_handshape.png`
- **Videos:** `D_sign.mp4`, `D_demo.mp4`, `D_slow_motion.mp4`

### Recommended Content

1. **Static Handshape Images:**
   - Front view of the hand forming the letter D
   - Side view (if applicable)
   - Close-up of finger positioning

2. **Video Demonstrations:**
   - Full sign demonstration
   - Slow-motion version for learning
   - Multiple angles if helpful

### How to Add Files

1. Place your image or video files directly in this folder
2. Follow the naming convention above
3. Ensure files are clear and well-lit
4. Recommended image resolution: at least 300x300 pixels
5. Recommended video resolution: 720p or higher

### Notes

- The letter D in ASL is formed with index finger pointing up, other fingers and thumb forming a circle
- Multiple views can help learners understand the proper handshape
- Consider including both static handshape and dynamic signing videos
